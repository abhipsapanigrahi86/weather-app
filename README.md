# 🌦 Weather App

A modern and responsive Weather App built using HTML, CSS, and JavaScript.

🔗 Live Demo:
https://abhipsapanigrahi86.github.io/weather-app/

---

## ✨ Features

- 🌍 Real-time weather data
- 📍 Current location weather
- 📅 5-day forecast
- 🌡 Temperature, humidity, wind speed
- 🌧 Rain animation
- ❄️ Dynamic weather effects
- 🌙 Auto day/night theme
- 📱 Mobile responsive UI
- 📊 Temperature chart
- 🗺 Live weather map
- ⚡ Fast and clean interface

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Chart.js
- Leaflet.js
